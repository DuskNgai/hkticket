# HKTicket 定点抢号工具

在指定时刻自动监视排队页面，入口按钮出现时自动点击，拿到排队位后提醒。

支持的购票网站(入口地址已内置，界面只选名字)：

- HCFC 歌迷会
- uutix(澳門演唱會)：开售前是演出详情页，按钮在开售时刻自动由「即將開售」变成「購買門票」，点击后进入选票页
- 自定义：粘贴任意排队入口地址

只需告诉程序在哪个网站、什么时间开售。

## 下载即用

`dist/` 目录提供三个操作系统(共四个文件)的单文件可执行程序，无需安装任何运行时：

- `hkticket-macos-arm64` — macOS(Apple 芯片)
- `hkticket-macos-intel` — macOS(Intel)
- `hkticket-windows.exe` — Windows
- `hkticket-linux` — Linux

## 使用

### 图形控制台

双击运行(或在终端不带参数运行)，会自动打开浏览器控制台页面。Windows 上优先用 Chrome 打开控制台，未安装 Chrome 时才用系统默认浏览器。选择购票网站、开售时间，点「开始」。输入过的参数会保存在程序同目录的 `settings.json`，下次启动自动填好。

### 命令行

```bash
./hkticket-macos-arm64 --site hcfc --time "2026-01-01 10：00：00"
```

时间按香港时区理解，与电脑所在时区无关。参数：

- `--site` 目标网站：`hcfc`(HCFC 歌迷会)/ `uutix`(uutix 澳門演唱會)/ `custom`(自定义);省略时使用上次保存的值
- `--url` 自定义入口地址，仅配合 `--site custom` 使用
- `--time` 目标时间，格式 `YYYY-MM-DD HH：MM：SS`;省略时使用上次保存的值
- `--lead` 提前开始监视的秒数，默认 15(入口按钮约在倒数 10–5 秒出现，默认覆盖整个窗口期)
- `--sessions` 独立会话数量(1–10)，默认 3;每个会话一个独立浏览器实例，各排一个号
- `--interval` 页面检查间隔(毫秒，最小 100)，默认 200
- `--timeout` 开售后多少秒仍未命中则放弃，默认 10
- `--driver` 浏览器驱动：`auto` / `safari` / `cdp`，默认 `auto`

所有参数输入一次即被记住，之后都可以省略。

### 多会话(一次排多个号)

会话数大于 1 时，程序为每个会话启动一个独立的浏览器实例，各自使用独立的会话目录、互不可见 Cookie，在排队系统眼里是不同的人，各自拿到独立的排队号。注意：

- 多会话只能用 Chrome / Edge;Safari 全系统共享 Cookie，多会话拿到的仍是同一个号。浏览器选「自动」且会话数大于 1 时程序会自动改用 Chrome / Edge，只有显式选 Safari 才报错
- 新建的会话目录(第 2 个起)没有保存过的人机验证 Cookie，首次使用需在每个窗口里手动过一次验证
- 每个会话是一个完整浏览器进程，内存占用随会话数线性增长，一般不超过 3–5 个

### 各平台使用的浏览器

- macOS：系统 Safari(需先开启一次：Safari → 菜单栏「开发」→ 勾选「允许 Apple 事件中的 JavaScript」;没有「开发」菜单则先在 Safari → 设置 → 高级 → 勾选「在菜单栏中显示开发菜单」)
- Windows：系统 Chrome 或 Edge(自动探测,优先 Chrome)
- Linux：系统 Chrome 或 Chromium(自动探测)

### 程序产生的数据

全部保存在程序同目录，整个文件夹拷到别的机器即可带走全部状态：

- `settings.json` — 上次输入的参数
- `browser-profile/`、`browser-profile-2/`… — Chrome/Edge 驱动的会话目录，每个会话一个(人机验证 Cookie 在这里)

### uutix

uutix 没有单独的排队入口页，流程与 HCFC 不同：

- 开售前停在演出详情页，右侧按钮显示「即將開售」，此时点击只会弹提示，不会排队
- 开售时刻页面自己把按钮切换成「購買門票」(选座模式为「選座購票」)，工具会在 0.5 秒内点中它；不需要刷新页面，刷新也不会影响(倒计时按服务器时间计算)
- 点击后同一标签页进入选票页(出现「節目場次」「票價種類」)，工具把这一步当作命中并保留窗口，之后由你继续选场次、选票、付款
- 第一次使用务必在工具打开的浏览器窗口里先登录 uutix；工具用的是自己的会话目录，不会带你在日常 Chrome 里的登录状态。万一没登录就点了，页面会被带到登录页，工具会保留窗口不关闭，登录后自动回到选票页
- uutix 前面有 EdgeOne 防护，偶尔会返回「當前購票人數過多」。工具识别到该页会自动重载，通常几次后即可恢复
- 内置地址是 `pId=4007`(張敬軒 x 澳門中樂團)。换其他演出时选「自定义」，粘贴形如 `https://www.uutix.com/detail?pId=演出编号` 的详情页地址

### 使用注意

- 出现人机验证(reCAPTCHA Enterprise)时，每个会话窗口都要各自点击一次复选框；控制台顶部会显示红色提醒并标出需要验证的会话编号(页面标签同时变成「⚠ 需要人机验证」)，工具还会把对应窗口置前
- 验证码资源来自 recaptcha.net 和 gstatic.com，方框加载不出来通常是网络无法访问，需要让系统浏览器走代理；验证令牌约 2 分钟有效，点击完成后尽快继续
- 系统时间偏差过大会导致验证失败，请先开启系统自动时间同步
- 程序启动时会做 NTP 校时;UDP 123 被拦截时自动改用 HTTPS 兜底校时(精度约 1 秒);两种方式都失败会拒绝运行，请检查网络或校准系统时钟
- 执行期间请勿关闭抢票用的浏览器窗口
- 拿到排队位或页面要求人机验证时，工具结束后会保留浏览器窗口，供继续操作
- 点击「停止」、启动阶段出错、或超时且未出现人机验证时，工具会自动关闭本次打开的浏览器窗口

## 从源码构建

需要 Go 1.27.3 及以上：

```bash
cd hkticket
go mod tidy
bash build.sh   # 一次产出全部四个平台到 dist/
```

## 目录说明

- `main.go` — 入口：无参数打开图形控制台，带参数按命令行运行
- `internal/core/` — 页面判定、监视循环、定时
- `internal/driver/` — 浏览器驱动(Safari / CDP)
- `internal/clock/` — NTP 校时
- `internal/settings/` — 参数记忆
- `internal/paths/` — 程序所在目录定位
- `internal/webui/` — 图形控制台
- `legacy/` — 旧 Python 版，仅归档，不再维护
- `DESIGN.md` — 架构设计说明
